# course-skills

Shared skills and agents for building university courses.

## Language

**Course repo**: A repository holding one course. Describes itself in a `COURSE.md`.

**Module**: One unit of a course, with notes, quizzes, exercises and discussion.

**Reviewer**: A read-only agent that checks one module along one axis: accuracy, style or alignment.

**Student run**: An attempt at one lab by an agent that knows only what a student knows (the student folder, public references, and the tracking issue if there is one), to find friction before release. It reports; it does not fix.
